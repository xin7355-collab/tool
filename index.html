複製指令去下載

一鍵下載：會直接跳到 a-Shell 並自動執行，不用貼上。勾幾支就一次抓幾支。
若沒反應（App 未安裝或系統擋跳轉），改按「只複製指令」→ 開 a-Shell → 長按貼上 → Enter。

指令前面那一長串是自動抓最新版程式用的 —— 有這段，手機上就永遠不用手動更新。

上傳 PDF、圖片或純文字

讀出來的文字會跟逐字稿放在同一個「📄 下載」分頁， 一樣有摘要、分類、關鍵字，也能一起打包下載。

會怎麼讀

電腦產生的 PDF（公文、報告、投影片匯出的那種）裡面本來就有文字， 直接抽出來——零錯字、幾秒就好，不經過任何辨識。

掃描件和照片才需要辨識，先用 AI 視覺模型讀（繁體中文最準， 表格版面也讀得懂），它讀不到才退回傳統 OCR。

照片會在你手機上先縮小再上傳，省流量也比較快。 拍的時候盡量拍正、光線平均，準確度差很多。

單檔 20MB 以內，PDF 一次最多讀 40 頁，可以一次選很多份。

上傳音檔

單檔 45MB 以內（約 1~2 小時），可以一次選很多個——會一個一個傳， 中間有一個失敗不影響其他的。

貼文章網址

抓回來的文章會跟逐字稿放在同一個「📄 下載」分頁， 一樣有摘要、分類、關鍵字，也能一起打包下載。

一般新聞、部落格直接就抓得到。若某個網站內容是靠 JavaScript 生出來的 而抓不到，跟我說一聲，可以開啟瀏覽器模式再試。

追蹤頻道

直接打名字搜尋就好；貼頻道網址、@帳號， 或那個頻道任何一支影片的網址也可以。
加進來之後，這個頻道的新片會在每天 05:30、12:00、21:30被檢查、自動抓成逐字稿。

加入時順便補抓最近幾支

補抓會立刻排進產線，長片一支可能跑十幾分鐘。只想收之後的新片就維持「不補抓」。

逗號分隔，不分大小寫。兩欄都空著＝這個頻道的新片全部都收。 加入之後還能在下面的頻道卡片上改，不用取消重加。

      更新狀態只是重讀一次進度，不會去抓東西。現在就找新片才會請系統馬上去看各頻道有沒有新片。

      這套東西是怎麼跑的？

      每天 05:30、12:00、21:30 三個時段， 自動檢查追蹤的頻道有沒有新片，有就抓成逐字稿放進「📄 下載」分頁。

      同樣那三個時段，也會把這段時間新完成的重點摘要收成一則通知送到手機 —— 用 GitHub App 收，所以手機要裝 GitHub App 並開啟通知。沒有新東西就不會發。

      抓片和彙整錯開一輪：這次排進去的片子產線要跑一陣子，會在下一個時段才報給你。 所以早上報昨晚轉完的、中午報早上排的、晚上報中午排的。

      剛加入的頻道不用等到隔天：存檔當下就會先查一次。
