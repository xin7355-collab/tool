## 摘要


**一句話**：AI工具讓公務員在電腦與手機上快速生成符合格式的公文，省去繁瑣搜尋與排版。

- 透過 Theris Studio 下載桌面客戶端，註冊帳號後即可使用免費配額生成公文，配額用盡需付費。  
- 若想完全免費，可在 OpenRouter 搜尋「MAIDSRE」申請 Microsoft 改版 DeepSeq API，並在 Chairage Studio 設定 API 金鑰後加入任意模型。  
- 在嵌入模型中選擇 BGE‑M3（或 OpenRouter 申請的模型）並將公文素材資料夾匯入知識庫，之後在對話頁面讓 AI 依據知識庫內容生成文件。  
- AI 產出的內容為 Markdown 格式，可使用線上轉換工具貼上後轉成 Word，再進行修改。  
- 手機端可利用飛書最新知識問答功能，上傳本地文件、音訊或影片，免費使用 DeepSeq R1 模型進行問答或生成公文。  
- 飛書知識問答目前仍處於適用階段，功能未完整但不限容量且免費，亦可申請內測並建立群組共享知識庫。  
- 以上方法讓公務員在電腦與手機上皆能快速查找、生成、共享公文，顯著提升工作效率
