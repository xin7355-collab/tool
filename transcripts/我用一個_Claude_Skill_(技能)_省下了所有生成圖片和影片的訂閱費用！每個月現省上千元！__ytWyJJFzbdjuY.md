## 摘要

- 在 Cloud 建立 Scale 技能，設定使用 Nano Banana 2 與 GPT Image Tool，並將 API Key 存於 .env 檔案以避免洩露；提示詞中指明使用「參考圖」資料夾與「完成檔」資料夾。
